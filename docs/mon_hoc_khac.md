# Tài Liệu Ôn Tập Môn Cơ Sở Dữ Liệu Nâng Cao

## 1. Giới thiệu
Tài liệu này dành cho môn Cơ sở dữ liệu, không liên quan đến đề tài đồ án Giám sát an ninh mạng SOC (Wazuh + Suricata).

## 2. Nội dung
- Tối ưu hóa chỉ mục Indexing trong MySQL.
- Thiết kế NoSQL với MongoDB.
- Phân tích hiệu năng câu truy vấn SQL (EXPLAIN query).
